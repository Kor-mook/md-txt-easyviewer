MD/TXT EasyViewer

1. MarkdownViewer.exe를 실행하면 바탕화면을 기본 위치로 열어 줍니다. 왼쪽의 문서 열기에서 파일을 선택할 수 있습니다.
2. 왼쪽 목록에서 문서를 선택합니다. 검색창의 폴더/지구본 버튼으로 현재 폴더 검색과 Windows 색인 전체 검색을 전환할 수 있습니다. 전체 검색은 색인된 MD·TXT만 포함합니다.
3. MD 또는 TXT 파일을 이 앱으로 열면 해당 파일과 같은 폴더부터 자동으로 보여줍니다.
4. 왼쪽에서 폴더를 눌러 들어가고, ..을 눌러 상위 폴더로 이동합니다. 파일은 MD와 TXT만 표시합니다.
5. 폴더 내용이 바뀌면 폴더를 다시 열어 최신 상태로 불러옵니다.
6. 상단 사이드바 버튼으로 접거나 펼칩니다. 접은 상태에서는 왼쪽 가장자리에 마우스를 올려 문서 위에 임시로 띄울 수 있습니다. 사이드바 경계를 드래그하거나 방향키로 너비를 조절할 수 있습니다.
7. 편집 버튼을 누르면 자동 감지된 편집기를 뷰어 안에서 선택할 수 있습니다. VS Code, Cursor, VSCodium, Sublime Text, Notepad++, Typora, 메모장을 확인하며, 목록에 없으면 직접 찾을 수 있습니다. 기본 편집기로 사용을 체크하면 다음부터 해당 편집기로 바로 열립니다. 설정에서 바꾸거나 해제할 수 있습니다.
8. 외부 편집기에서 열린 문서를 저장하면 뷰어가 약 2초 간격으로 변경 사항을 확인하여 반영합니다.
9. 상단 화살표나 마우스 뒤로·앞으로 버튼으로 열어 본 문서를 이동합니다. 새로 설치하면 탭은 기본적으로 켜져 있으며 설정에서 끌 수 있습니다. 탭을 켜면 일반 클릭은 현재 탭을 바꾸며, Ctrl+클릭·마우스 가운데 클릭 또는 파일 우클릭의 새 탭 메뉴로 별도 탭을 엽니다. 이미 열린 문서는 기존 탭으로 이동합니다.
10. 상단의 −, +, ↺ 버튼, Ctrl+마우스 휠, Ctrl+−, Ctrl++, Ctrl+0으로 문서 크기를 조절합니다. TXT의 긴 줄은 창 폭에 맞춰 자동 줄바꿈됩니다.
11. 인쇄 버튼 또는 Ctrl+P는 문서 본문만 인쇄합니다. 머리글·바닥글은 기본적으로 꺼지며 인쇄 창에서 바꿀 수 있습니다.
12. 우클릭 메뉴에서 복사, 전체 선택, 새로고침, 인쇄를 사용할 수 있습니다.
사이드바 위에서 마우스 앞뒤 버튼을 누르면 폴더 이동 기록을, 문서 영역에서는 문서 이동 기록을 따라갑니다.
처음 실행하면 사용법 안내가 표시되며, 설정에서 다시 볼 수 있습니다.
13. 설정의 Language에서 언어를 선택합니다. 기본 언어는 English이고 한국어를 선택할 수 있습니다. locales 폴더의 en.json, ko.json을 직접 교체할 수 있으며, 같은 형식의 JSON 파일을 추가하면 언어 목록에 나타납니다. 파일 이름은 영문자·숫자·밑줄·하이픈만 사용하고, name은 언어 이름, strings는 문구 키와 번역 문자열로 구성합니다. 누락된 문구는 영어가 표시됩니다.

연결 프로그램 설정: .md 파일을 마우스 오른쪽 버튼으로 클릭 → 연결 프로그램 → 다른 앱 선택 → PC에서 앱 선택 → MarkdownViewer.exe 선택 → 항상 사용.
Windows 버전에 따라 메뉴 이름이 조금 다를 수 있습니다. index.html, app-icon.ico 및 locales 폴더를 exe와 같은 폴더에 보관하세요.

문서와 이미지의 상대 경로는 선택한 폴더 안에서 연결됩니다.
제목, 기본 목록, 체크박스, 표, 인용, 코드 블록과 일반 링크를 지원합니다.
복잡한 중첩 목록, 확장 문법, HTML은 완전하게 지원하지 않습니다.
브라우저의 폴더 선택 기능을 이용하므로 폴더 선택 시 접근 확인 창이 나타날 수 있습니다.
문서는 읽기 전용이며 외부 라이브러리를 설치하지 않습니다. 앱 창은 설치된 Microsoft Edge를 사용합니다.
실행 중인 뷰어는 현재 PC의 임시 로컬 주소를 통해 선택한 폴더의 문서를 읽습니다. 인터넷 서버로 전송하지 않습니다.
뷰어 프로세스는 마지막 요청 후 최대 12시간 동안 유지됩니다.

Markdown 수식: 본문에서 $x^2$를, 별도 줄에서 $$\frac{1}{2}$$ 또는 여러 줄의 $$ 블록을 사용합니다. 분수, 근호, 위·아래 첨자, 그리스 문자와 기본 연산 기호를 지원합니다. 행렬(matrix, pmatrix, bmatrix, array 등), 경우 나누기(cases), 여러 줄 정렬(aligned)도 지원합니다. 지원하지 않는 LaTeX 명령은 원문으로 표시됩니다. math-renderer.js를 exe와 같은 폴더에 보관하세요.
